# Web公開ディレクトリ

このディレクトリは GitHub Pages で配信する閲覧用ファイルです。正本はリポジトリ直下の `data/` にある YAML で、`data/` 以下の JSON は公開用の派生物です。

- `index.html`：正式公開の観測値閲覧画面
- `app.js`：年月日・記録時刻の選択、観測値とグラフの表示
- `site-shell.js`：正式ページとプレビューで共通利用するヘッダー・フッター、ナビゲーションの生成
- `site-shell.css`：共通ヘッダー・フッターのスタイル
- `style.css`：画面のスタイル
- `data/index.json`：公開対象の年月一覧
- `data/YYYY/MM.json`：正本YAMLから生成した観測値
- `preview/index.html`：観測データの表示処理は独立した操作確認用画面（共通ヘッダー・フッターのみ共有）

原資料の空欄、観測予定なし、未提供の観測要素、数値0は混同しません。記録時刻はその日の観測レコードに基づきます。データの出典と検証についてはルートのREADMEと採録方針を参照してください。

更新時は生成処理と表示を検証し、最後に実際のディレクトリ内容を確認してこのREADMEを更新します。
