# 採録方針

## 1. 目的

この文書は、日立市天気相談所が公開する日立市役所観測所の資料を、年代による違いを失わずに採録するための規則を定める。

本アーカイブは、原資料を一律の形へ見せかけることを目的としない。観測要素、観測時刻、帳票構造、空欄や記号の意味が年代によって異なる場合は、その違い自体を来歴情報として保持する。

## 2. 収録範囲

当面の収録対象は、日立市役所観測所とする。

日立市役所観測所について1953年から最新公開年までの整備が完了した後に、ほかの観測所の資料状態、利用条件、継続性を確認し、収録可否を検討する。

## 3. 採録区分

### 3.1 歴史資料期：1953–1999年

- 1953–2007年一括資料に含まれる、観測要素ごとの年別Excel帳票を原資料とする。
- 実際に記録された観測時刻だけを採録し、存在しない時刻を補って毎時観測に見せない。
- 時刻別観測値と、日平均、日合計、最高、最低などの集計値を分離する。
- 観測要素ごとの収録開始年を確認し、当該年の公開資料に含まれない要素を欠測として扱わない。
- 原資料に残る空欄、ハイフン、文字列、時刻表記は、意味を確認してから正規化する。
- 1953–2007年一括ZIPのうち、正本生成には1953–1999年の年別Excelを使用する。

### 3.2 移行期：2000–2013年

- 年・観測要素ごとに公開されたExcel帳票を原資料とする。
- 各年の帳票構造に従い、観測時刻、観測要素、表記の違いを保持する。
- 歴史資料期や現行資料期と項目名が似ていても、意味や集計区間を確認せずに同一視しない。
- 2000–2007年は一括ZIP版とも重複するが、後年に修復・差し替えられた可能性があり、
  現行の年別公開ページで配布されている個別Excelを正本生成に使用する。
- 同期間の一括ZIP版は代替出典としてURL、アーカイブのSHA-256、内部ファイル名、
  内部ファイルのSHA-256および個別版との比較結果を記録する。

### 3.3 現行資料期：2014年–現在

- 年・観測要素ごとに公開された現行形式のExcel帳票を原資料とする。
- 出典ページ、ファイルURL、取得日、公式ページの更新日、SHA-256を記録する。
- 「現在」は暦上の当年ではなく、公式サイトで年別観測ファイルが公開されている最新年までを指す。
- 当年の途中経過を毎時または毎日収集せず、年別ファイルの公開後に年単位で採録する。

## 4. 値が存在しない状態の区別

値が存在しない理由を、少なくとも次の状態に分ける。

| 状態 | 意味 |
| --- | --- |
| `source_blank` | 原資料の対象欄が空白である。意味を推測して0へ変換しない。 |
| `missing` | 観測または記録の対象だが、値を確認できない。根拠を確認できた場合に用いる。 |
| `not_available_for_period` | その年代の公開資料に、当該観測要素が収録されていない。 |
| `not_applicable` | そのレコードに当該要素を適用すること自体が適切でない。 |

`not_available_for_period`は「当時、観測していなかった」という断定ではない。公開資料から確認できる範囲で、当該期間の資料に収録されていないことを示す。

## 5. 正本の分担

- 観測値、収録期間、観測時刻、状態、出典、ファイルハッシュなど、機械的に処理する事実情報はYAMLを正本とする。
- 状態の意味、資料構造の変化、解釈上の注意など、人に向けた説明はMarkdownを正本とする。
- JSON、CSV、Webページは、正本のYAMLとMarkdownから生成する派生物とする。
- 派生物だけに独自の事実や説明を書き加えない。

### 5.1 複数の公式配布版

同じ年・観測要素に複数の公式配布版がある場合、正本生成に使用したものを主原資料、
比較・検証に使用できるものを代替原資料として区別する。複数の配布版の値を一つの
月別YAMLへ混在させない。採用した版、判断根拠、比較結果は出典マニフェストに記録する。

## 6. 更新頻度

- 公式データページの最新公開年を原則として月1回確認する。
- 新しい年のファイルが公開された場合は、その年の全観測要素を一括して取得・検証・採録する。
- 過去年の原資料は採録時にSHA-256を記録する。
- 過去年の資料に訂正告知があった場合、または定期的な再確認を行う場合は、記録済みのハッシュと比較する。
- リアルタイム、毎時、毎日の観測値収集は行わない。
- GitHub Actionsは毎月1回、公式ページに掲載された最新公開年を確認する。
- 手動実行時は2000年以降の任意年を指定でき、12か月をまとめて再生成する。
- 1953–1999年の一括ZIP資料は別の遡及収集処理で扱い、年別Excel用処理へ混在させない。

## 7. 確認できない事項

確認できない事項を推測で補わない。値は`null`、状態は適切なフラグ、説明は注記として記録し、後から根拠を追記できる形を保つ。
