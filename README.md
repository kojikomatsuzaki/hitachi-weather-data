# 日立市天気相談所 観測データアーカイブ

日立市天気相談所が公開する気象観測データを、機械可読な形式で整理・保存するデジタルアーカイブです。

## 現在の収録対象

- 観測所：日立市役所観測所
- 収録済み：1953年、2000年、2014年、2025年の各1月
- 観測要素：気温、湿度、降水量、現地気圧、海面気圧、全天日射量、日照時間、風速、風向、露点温度、天気
- 正本形式：YAML

日立市役所観測所について、1953年から公式サイトの最新公開年までを順次整備します。
ほかの観測所は、この観測所の整備が完了した後に収録可否を検討します。

## データ出典

- [日立市天気相談所](https://tenki.city.hitachi.lg.jp/)

### 年代別の原資料

| 対象年 | 正本生成に使用する原資料 | 備考 |
| --- | --- | --- |
| 1953–1999年 | 1953–2007年一括ZIP内の年別Excel | 観測要素別ZIPから対象年を抽出します。 |
| 2000–2007年 | 年・観測要素別の個別Excel | 一括ZIP版と重複しますが、後年に更新された個別版を優先します。 |
| 2008年–最新公開年 | 年・観測要素別の個別Excel | 公式ページで公開されている最新版を使用します。 |

2000–2007年には、一括ZIP版と個別配布版の双方が存在します。本アーカイブでは、
公式ページで継続的に更新され、一部ファイルの修復・差し替えが確認できる個別配布版を、
正本生成の原資料として採用します。一括ZIP版は、比較・検証のための代替出典として
来歴情報を記録します。

## データ整備方針

- YAMLを正本とします。
- JSONやCSVなどは、正本のYAMLから生成します。
- 出典、取得日、観測所、観測要素などの来歴情報を記録します。
- 原資料の内容と、整理・変換したデータを区別します。
- 観測対象でありながら値を確認できない「欠測」と、その年代の公開資料に観測要素が収録されていない状態を区別します。
- 機械的に処理する事実情報はYAML、状態の意味や資料解釈上の説明はMarkdownを正本とします。
- Webページは、正本のYAMLとMarkdownから生成する派生物として扱います。

詳しい採録規則は、[採録方針](docs/collection-policy.md)を参照してください。

## 採録区分

原資料の構造と提供形態の違いに応じて、採録規則を三つの期間に分けます。

| 区分 | 対象年 | 基本方針 |
| --- | ---: | --- |
| 歴史資料期 | 1953–1999年 | 要素ごとの年別帳票から、実際に記録された時刻と集計値を区別して採録します。 |
| 移行期 | 2000–2013年 | 当該期間の帳票構造に従い、歴史資料期との項目・時刻・表記の違いを保持します。 |
| 現行資料期 | 2014年–現在 | 現行の公開ファイルから採録し、取得日、公開更新日、URL、ファイルハッシュを記録します。 |

ここでいう「現在」は暦上の当年ではなく、日立市天気相談所が年別観測ファイルを公開している最新年までを指します。
2026年10月8日の確認時点における最新公開年は2025年です。

## 更新方針

本リポジトリはリアルタイムの気象観測システムではなく、公開済みの年別観測資料を整理するデジタルアーカイブです。

- 公式データページの更新状況は、原則として月1回確認します。
- 新しい年のファイルが公開された場合は、その年の観測要素を年単位で一括採録します。
- 観測値を毎時または毎日、自動取得することは行いません。
- 過去年の原資料は採録時にSHA-256を記録し、訂正告知または定期確認の際に同一性を確認します。

## データの再生成

原Excelファイルは再配布条件を確認中のため、リポジトリへ複製していません。
変換時には、出典マニフェストに記録したURLから取得し、SHA-256が一致したファイルだけを使用します。

```console
python -m pip install -r requirements.txt
python scripts/import_hitachi_city_hall_2025.py --month 1 --download-missing
```

この処理から、正本YAMLと検証報告が生成されます。

- `data/hitachi-city-hall/2025/01.yaml`
- `reports/validation-2025-01.md`

1953年1月は、観測要素ごとのZIPに含まれる年別Excelから生成します。

```console
python scripts/import_hitachi_city_hall_1953.py --month 1 --download-missing
```

- `data/hitachi-city-hall/1953/01.yaml`
- `reports/validation-1953-01.md`
