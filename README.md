# 日立市天気相談所 観測データアーカイブ

日立市天気相談所が公開する気象観測データを、機械可読な形式で整理・保存するデジタルアーカイブです。

## 現在の収録対象

- 観測所：日立市役所観測所
- 対象年：2025年
- 観測要素：確認中
- 正本形式：YAML

今後、2014年、2000年、1953年へと順次遡って整備する予定です。

## データ出典

- [日立市天気相談所](https://tenki.city.hitachi.lg.jp/)

## データ整備方針

- YAMLを正本とします。
- JSONやCSVなどは、正本のYAMLから生成します。
- 出典、取得日、観測所、観測要素などの来歴情報を記録します。
- 原資料の内容と、整理・変換したデータを区別します。

## 注意事項

本リポジトリは、日立市天気相談所の公式リポジトリではありません。  
公開データの権利および利用条件については、出典元の定めに従います。
